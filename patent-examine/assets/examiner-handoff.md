## Requested output

Examine every pending claim and all formal matters. Return a complete simulated
Office Action, `ALLOWABLE`, or `INCOMPLETE` decision using the exact protocol. State
search limitations honestly; no missing input counts in the applicant's favor.
Perform the completeness gate first. If a gating input is missing, return
`INCOMPLETE` promptly with the exact deficiency list and preliminary visible defects;
do not launch an open-ended merits search that cannot produce a valid clearance.
For every 102/103 ground, include a reference-substance synopsis and contextual claim
chart that identifies the actual relied-on embodiment, mapping mode, and technical
match. Be prepared to reread the full reference and answer a focused
`PRIOR_ART_ACCURACY_CHALLENGE` before the applicant narrows a claim.
